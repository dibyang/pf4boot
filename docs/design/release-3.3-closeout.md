# 3.3.0 发布收口

[English](en/release-3.3-closeout.md)

## 冻结范围

以 `7ef78c0` 为代码基线，冻结 3.3 功能。仅完成发布版本、升级说明、最终制品与升级验收；不新增 API、运行依赖或生命周期机制。修复真实验收发现的阻断问题须记录原因并重验最终制品。

## 三项门槛

1. 版本确定为 `3.3.0`，同步 CHANGELOG 和发布说明，列明默认行为、必要的行为修正、迁移与回滚限制。
2. 使用真实 Java 8 完整构建并执行 `publishToMavenLocal`；独立消费工程仅从 Maven 发布坐标获取 11 个框架模块，不使用 project/includeBuild 替代。检查 JAR、POM、源码、Javadoc、内部版本及运行 classpath。
3. 最终候选复用双平台封存验收；额外使用保留的 3.2.0 原始发行 ZIP，不重编译旧插件。以跨插件 JPA 用户/图书/审计业务作为项目内代表性业务，验证事务、重复启停、升级保留数据和备份恢复回滚。按用户要求不验证外部业务包，不宣称覆盖用户生产插件。

## 兼容与边界

- 默认不启用 production profile。原始 3.2.0 ZIP 没有新版签名清单，应在默认模式验证兼容，在严格模式明确拒绝；不修改旧 ZIP、伪造历史签名或绕过门禁。
- 回滚以成功排空和关闭为前提。保留旧宿主、旧插件、配置及离线数据/记录备份；恢复整套旧快照。不承诺旧框架能读取所有新版治理记录，也不以新版本已成功写入来推断反向兼容。
- 同一批 Java 8 编译字节码在 Windows 与 Linux 运行。Linux 使用已有低权限用户、隔离目录及回环端口，不改变系统服务或 Java。
- 本轮不自动提交、推送、打标签、部署或发布到中央仓库；正式发布仍需明确授权和人工中央仓库操作。

## 验收状态

2026-11-04，三项门槛均通过，版本为 `3.3.0`，未正式发布。没有修改框架运行代码；仅修正样例控制台仍指向 SNAPSHOT 文件名的默认输入，并补充回归断言。

- 真实 Java 8 完整构建、本地 Maven 发布及独立 POM 消费通过；11 个最终构建/发布/消费 JAR 哈希一致，源码、Javadoc、POM 与签名齐全，55 个附件签名离线验证通过，框架字节码不高于 52。
- Windows 8u431 与 Linux 8u312 各通过 366 项 JUnit、三套真实宿主和四套既有旧包升级，共 16 项矩阵检查。另各通过原始 3.2.0 的业务初始化、3.3.0 独立消费宿主升级（20 次 restart、10 次 reload）、旧备份回滚及严格模式拒绝，共四项检查。
- 旧插件 ZIP 未改动；旧发行包中的 11 个框架 JAR 与保留的 Maven Local 3.2.0 制品一致。两版外置 application.yml 哈希相同，验收没有通过修改旧配置放宽兼容条件。
- Saga/Outbox smoke 通过；基础模板 hello、插件版本/STARTED 状态及正常关闭通过；控制台回归和最终完整构建通过。
- 两端执行后 1,167 个封存输入均未变，端口 17832 及本地模板端口 17833 已释放。Linux 只使用临时目录和已有 nobody 用户，未改变系统服务或 Java。

最终包、哈希、报告位置及命令见 [3.3.0 发布说明](../release-notes/3.3.0.md)。导出过程修正了 Groovy 字符串插值与 XML API 两处验收脚本错误；两份不完整导出目录保留为失败证据，未用其结果冒充最终候选。
